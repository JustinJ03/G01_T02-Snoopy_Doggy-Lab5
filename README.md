Task: Creating a Restaurant Menu
In this lab, you are required to develop a simple Flutter Restaurant Menu App using Card widgets.

Requirements:

Create a new Flutter project named restaurant_menu.

Design a single-screen restaurant menu interface.

Display three Card widgets, each representing a different type of food.

Use appropriate Flutter widgets to organize and design your restaurant menu.

Extra Task (Optional):

Implement navigation so that when a user taps any food Card, the app opens another screen displaying information about the selected food.

GitHub Submission Instructions
Complete the assigned lab task.

Push your Flutter project to GitHub.

Make sure your repository is Public and contains all necessary project files.

Each student must submit their GitHub repository link individually, even when working in a group.

Ensure your GitHub link is accessible and your project runs successfully.
